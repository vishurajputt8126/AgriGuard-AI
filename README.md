# AgriGuard AI

A small machine learning project for predicting crop disease risk from agricultural and environmental conditions.

## Project idea
The goal is to study whether factors such as crop type, temperature, humidity, rainfall and soil conditions can be used to estimate crop disease risk.

## Planned workflow
1. Select and document a suitable public dataset.
2. Inspect missing values, duplicates and class distribution.
3. Clean and preprocess the data.
4. Create useful features.
5. Train a baseline model.
6. Compare Logistic Regression, Decision Tree and Random Forest.
7. Evaluate precision, recall, F1-score and other suitable metrics.
8. Document limitations and improvements.
